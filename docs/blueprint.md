# **App Name**: TitleForge AI

## Core Features:

- Topic Category Selection: Allow users to select from predefined categories such as BSIT, Computer Science, Computer Engineering, or Electrical Engineering.
- Topic and Difficulty Selection: Provide choices for specific topics within each category (e.g., Data Mining for Computer Science) and allow for a custom topic text field. Offer a difficulty level selection (Beginner, Intermediate, Advanced).
- Title Generation: Generate a thesis/capstone project title based on the selected category, topic, and difficulty using AI. The tool generates appropriate and relevant titles by analyzing the relationships between topic keywords and project scope.
- Detailed Output Generation: Generate additional details, including suggested tech stacks, project objectives, project descriptions, implementation steps, methodologies, and estimated completion time using AI. The tool reasons about appropriate approaches for projects of various scope and difficulty levels, so its suggestions should reflect those selections.
- Interactive Display: Display all generated information in an interactive and user-friendly format.

## Style Guidelines:

- Primary color: Dark ocean blue (#1E3A8A) to evoke a sense of professionalism and depth.
- Background color: Very dark blue (#0F172A), providing a clean backdrop for content and reducing eye strain.
- Accent color: A brighter, slightly lighter blue (#3B82F6) to highlight key interactive elements.
- Font pairing: 'Space Grotesk' (sans-serif) for headings and 'Inter' (sans-serif) for body text, creating a modern and readable experience.
- Use clear and simple icons to represent categories and options, enhancing usability.
- Ensure the layout is responsive, adapting to different screen sizes and devices for optimal viewing.
- Implement primer motion effects and skeleton loading to provide a smooth and engaging user experience during data loading.
